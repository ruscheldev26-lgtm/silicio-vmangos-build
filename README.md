# VMaNGOS 1.5.1 — build experimental separado

Somente baseline Windows x64 Release, build 4449, fonte publico vmangos/core em e968eae18407ea557064c32f4fdcea96464f5372.

Workflow exclusivamente manual, runner windows-2022, no maximo tres horas. Nao contem SilicioAI. Nao executa os servidores nem implementa um jogador autonomo.

Nao recebe arquivos de instalacao local, bancos de jogadores, credenciais, mapas, configuracoes de servidor ou memorias de conversa. O artefato e composto por binarios, fontes publicos, receita e evidencia de compilacao.

A publicacao deste repositorio e o disparo do job dependem das autorizacoes do operador. Runner padrao publico tem processamento gratuito; disponibilidade de cota e bloqueio de gastos devem ser conferidos antes de permitir upload de artefatos. Retencao proposta: um dia.

As dependencias permanecem as previstas na revisao do projeto. Os fontes e LICENSE sao incluidos para revisao e reconstrucao. Nenhum executavel gerado deve ser implantado sem validacao estatica e teste isolado posteriores.
